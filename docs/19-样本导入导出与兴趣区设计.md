# 监督分类：兴趣区（AOI）叠加 + 样本导入导出 设计

> 场景：在本地高清影像上做监督分类时，用户需要
> ① 除了整幅，还能叠一个**兴趣区**（矿权边界 / 手绘多边形）；
> ② 样本能在不同机器、不同人之间**流转**（在 QGIS/ArcGIS 里画好点导进来，或在平台画好导出去送审）。

---

## 一、兴趣区（AOI）设计

### 1.1 三种来源，一套选择器

```
AOI  [整幅影像] [从边界加载 ▾] [手绘]  ·  当前：宁都河源矿权 246.74 ha  [清除]
```

| 来源 | 用途 | 说明 |
|---|---|---|
| **整幅影像** | 默认 | 直接按影像四至分类，不额外裁 |
| **从边界加载** | 常用 | 复用「边界管理」里导入的矿权/扰动边界，与在线模式口径一致 |
| **手绘** | 临时 | 在地图上点选多边形，仅本次有效；可一键「存为边界」沉淀下来 |

### 1.2 叠加显示（这是当前缺的）

- 影像贴图之上再叠一层 **AOI 描边 + 半透明填充**（青色），一眼区分「影像范围」与「分类范围」
- 分类结果只保留 AOI 内像素，AOI 外置透明；右侧显示「AOI 246.74 ha / 影像 1030 ha」
- 结果保存时 `aoiJson` 写 AOI（不是影像四至），这样时序指纹才能和在线解译对上

### 1.3 后端要改的一处（已知 bug）

`supervised_local.py` 里把 AOI 转成像素多边形后 rasterize，掩膜算出来是空的
（上一轮实测「样本全部越界」，我临时加了「为空则退回整幅」的兜底）。

**正确修法**：用 `rasterio.features.geometry_mask` + `Affine.identity()`，
几何坐标用 `(col, row)` 且 **row 需按 `out_h - 1 - row` 翻转成向上为 y**，
rasterize 内部才与影像行号方向一致。修完删掉兜底逻辑，改为真正裁剪。

## 二、样本导入导出设计

### 2.1 格式选择

| 格式 | 定位 | 理由 |
|---|---|---|
| **CSV**（主） | 人看、Excel 改、送审 | 客户和你同事都会用；一行一个点，最不容易出错 |
| **GeoJSON**（次） | GIS 软件互通 | QGIS/ArcGIS 直接打开，点位带类别属性 |
| ~~SHP~~ | 不做 | 多文件、编码乱，投入产出不划算（需要时让用户先转 GeoJSON） |

**CSV 结构**（首行表头，UTF-8 带 BOM 以便 Excel 直接打开不乱码）：

```csv
# schema=v1
# imagery=茜坑锂矿2022.tif
# aoi=116.014,26.466,116.030,26.480
# exported=2026-10-22T16:40:00+08:00
classType,lng,lat,note
VEGETATION,116.0181,26.4702,北坡林地
BARE,116.0215,26.4721,
WATER,116.0246,26.4733,坑内积水
```

- `classType`：标准码（PIT/DUMP/TAILINGS/BARE/ROAD/VEGETATION/WATER），也接受中文
- 注释行 `#` 记录元信息：影像名、AOI 四至、导出时间、平台版本 → **可复现**
- 列名容错：`class/type/类型`、`lon/x/经度`、`lat/y/纬度` 都能识别

### 2.2 导入流程（四步，全程给反馈）

```
选文件 → 解析 → 校验报告 → 确认合并
```

**校验项**（缺一个都会在报告里列出来）：

| 检查 | 处理 |
|---|---|
| 表头识别 | 找不到经纬度列 → 直接报错并告诉它期望的列名 |
| 类别码 | 中文/别名 → 归一到标准码；无法识别 → 计入「未知类别」并列出 |
| 坐标系 | 值超出 ±180/±90 → 判定为投影坐标，报错要求先转 WGS84（不猜） |
| 落在影像外 | 单列「越界点」，可选「丢弃」或「保留」（保留时分类时会自动忽略） |
| 重复像元 | 同一 10m/0.5m 像元只保留一个（否则精度虚高） |
| 样本量 | 按类统计，提示「植被 25 个 ✅ / 采坑 3 个 ⚠ 至少 8 个」 |

**报告示例**：

```
共读取 48 行：有效 41，重复像元 4，越界 2，未知类别 1
按类：植被 18、裸地 12、水体 11
⚠ 水体只有 11 个，建议补到 20 个以上；采坑类未提供
```

导入策略：**合并**（默认，去重后追加）或 **替换**（清空后导入）。

### 2.3 导出

- **导出 CSV**：当前样本 + 元信息头（影像、AOI、日期、类别统计）
- **导出 GeoJSON**：`FeatureCollection`，属性带 `classType`、`index`，QGIS 里按类别着色即可检查
- 导出即下载，文件名 `样本_茜坑锂矿2022_20261022.csv`

### 2.4 样本集入库（P1，建议做）

只在文件里流转有个问题：**换台机器就找不到上次标的样本**。建议加一张表：

```sql
CREATE TABLE sample_sets (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  project_id BIGINT NOT NULL,
  name VARCHAR(120) NOT NULL,
  imagery_id BIGINT NULL,
  aoi_signature VARCHAR(32) NULL,   -- 与解译记录同一套指纹
  point_count INT,
  class_stats JSON,                  -- {"VEGETATION":18,...}
  points_json LONGTEXT,              -- [{classType,lng,lat,note}]
  created_by VARCHAR(64),
  created_at DATETIME
);
```

- 页面上：「保存样本集」「加载样本集」（下拉选历史样本集，一键恢复）
- 价值：演示时可以说「这套样本上次已经标好，直接复用」；也支持多人协作

## 四、口径与风险

1. **导入样本不校验"标得对不对"**，只校验格式与范围——标错类别是人的问题，平台只能给出「类间光谱重叠」提示
2. 导出文件含坐标，属项目数据；默认不加密码，但**不应提交到代码库**（`.gitignore` 里加 `样本_*`）
3. AOI 掩膜修好后，分类结果面积会变小（只算 AOI 内），历史记录不受影响
4. 样本集入库后，删除项目要级联清理，避免孤儿数据
