# 智慧矿山平台 · 功能扩展清单

> 版本：2026-10-20
> 目标：在现有五大功能域（总览 / 遥感解译 / 监测告警 / 报告中心 / 平台管理）基础上，
> 新增 **12 个**功能，全部可落地、不重复造轮子、能直接增强向客户演示的说服力。
> 每个功能标注「做什么 / 作用 / 融入位置 / 技术要点 / 优先级」。

## 优先级说明

- **P0（必做）**：直接影响演示拿单，优先实现

## 一、遥感解译域（增强核心能力）

### 1. 多期对比热力图（P0）

- **做什么**：在变化分析页，把同一 AOI 两期提取结果做空间叠加，用红蓝双色渲染「新增扰动区」（红）和「恢复植被区」（绿），并输出变化面积统计。
- **作用**：客户最关心「矿山到底扩张到哪了、哪些地方在复绿」。现在只有面积数字和静态叠加，缺一张「一眼看懂变化在哪」的热力图。这是演示的核心爆点。
- **融入位置**：报告中心 → 数据分析页，新增「变化热力图」面板；复用 RemoteExtractView 已有的双色叠加逻辑（showDiff），后端加一个空间求差接口。
- **技术要点**：
  - 后端新增 `POST /api/analysis/diff-heatmap`，输入两期 features（GeoJSON），用 shapely 做多边形求差（`difference`），返回新增/消失两块几何
  - 前端用 Cesium 双色 polygon 渲染 + 图例
  - 复用现有 aoiSignature 保证两期是同一 AOI

### 2. 变化检测自动预警（P0）

- **做什么**：系统定时对已有时序数据做面积趋势检测，当某类地物（如采坑、裸地扰动）面积环比增长超过阈值时，自动生成一条预警记录并推送。
- **作用**：把「被动看数据」变成「主动预警」，体现平台的监测价值。这也是「监测预警」四个字里「预警」在遥感侧的真实落地。
- **融入位置**：复用现有 `warning_rules` / `alarms` 表结构，新增一类「遥感预警」规则；总览页告警数自动纳入。
- **技术要点**：
  - 后端新增 `POST /api/analysis/check-trends`（或定时任务），遍历时序组算环比增幅
  - 超过阈值 → 写入 alarms 表（新增 alarmType=RS_TREND）
  - 阈值在预警设置页配置（复用 WarningRulesView）

### 3. 影像波段组合切换（P1）

- **做什么**：遥感提取/影像浏览时，支持切换常用波段组合——真彩色（B4/B3/B2）、假彩色（B8/B4/B3）、NDVI 假彩色、短波红外增强等。
- **作用**：不同波段组合能凸显不同地物（如假彩色看植被、SWIR 看水体/裸地），是遥感专业性的体现，也能让客户看到「专业工具」的观感。
- **融入位置**：遥感提取页 + 影像库预览，加一个波段组合下拉。
- **技术要点**：inference 的 `true_color_png` 扩展为 `composite_png(bands, formula)`，前端传波段组合参数。

### 4. 地物分类结果统计报表（P1）

- **做什么**：对一次解译结果，自动生成「分类统计卡片」——各类型面积、占比、斑块数、最大斑块面积，配饼图。
- **作用**：现在提取完只有覆盖率一个数字，缺结构化的分类统计。补上后解译结果更完整、更专业。
- **融入位置**：遥感提取页结果面板 + 报告中心数据分析页。
- **技术要点**：前端对 features 按 classType 聚合统计即可，无需后端改动（或后端 `/save` 返回时附带统计）。

## 二、监测告警域（IoT 增强）

### 5. 传感器实时大屏（P1）

- **做什么**：GIS 大屏上叠加传感器点位，实时刷新位移/水位/应力等数据，超阈值点位闪烁 + 弹出告警。
- **作用**：现在传感器数据在表格里，不够直观。放到三维地图上，客户能看到「哪个监测点在哪个位置、状态如何」，IoT 价值立现。
- **融入位置**：总览驾驶舱 / GIS 大屏，传感器点位 entity + WebSocket 实时推送。
- **技术要点**：
  - 复用 `sensorApi.list` 拿点位，Cesium billboard 标注
  - WebSocket 推送（后端已有 WS 预留），或用前端轮询（demo 期够用）

### 6. 告警闭环处理流程（P1）

- **做什么**：告警从「产生 → 认领 → 处理 → 关闭」全流程闭环，带处理人、处理意见、时间戳。
- **作用**：现在告警只有「未处理/已确认」两态，缺闭环。补上后体现平台是可真正用于运维管理的系统，而非演示玩具。
- **融入位置**：告警日志页，加处理按钮 + 处理弹窗 + 状态流转。
- **技术要点**：
  - alarms 表加 handledBy / handleComment / handleTime 字段
  - AlarmController 加 `/ack`、`/resolve` 端点（已有 ack，扩展 resolve）
  - 前端告警列表加操作列

### 7. 传感器数据导出（P2）

- **做什么**：把传感器历史数据导出为 CSV/Excel。
- **作用**：客户（尤其技术对接方）经常要拿数据走。一键导出很实用。
- **融入位置**：设备监测页，加「导出」按钮。
- **技术要点**：后端 `sensorApi` 加导出端点，生成 CSV；或用 workbuddy-sheet-generation 生 Excel。

## 三、报告中心域（增强交付物）

### 8. 报告模板定制与历史管理（P1）

- **做什么**：报告支持选择模板（默认/简洁/详细）、填写矿区基本信息（矿权、位置、负责人）、报告历史列表可下载/删除。
- **作用**：现在报告是「一键生成」，缺定制和历史管理。补上后报告功能完整，可反复生成不同版本的报告。
- **融入位置**：报告中心 → 报告生成页，加「模板选择」+「历史报告」列表。
- **技术要点**：
  - 后端新增 report 表（id/projectId/文件名/生成时间/下载路径）
  - inference report.py 支持模板参数

### 9. 报告在线预览（P2）

- **做什么**：生成 Word 报告前，先在网页上预览核心内容（不下载就能看）。
- **作用**：避免生成才发现数据不对，反复下载。预览可提升体验。
- **融入位置**：报告生成页，生成按钮旁加「预览」。
- **技术要点**：ReportView 已有「报告预览」数据概览卡片，扩展为完整章节预览。

## 四、平台管理域（完善后台）

### 10. 操作日志审计（P1）

- **做什么**：记录所有关键操作（登录、删除、提交解译、导出报告、修改权限），管理员可查。
- **作用**：企业级系统标配，体现平台的安全性和可追溯性，向客户展示「我们是认真做系统的」。
- **融入位置**：平台管理 → 新增「操作日志」页。
- **技术要点**：Spring AOP 切面 + audit_log 表（userId/action/entity/timestamp），前端列表查询。

### 11. 数据字典与单位管理（P2）

- **做什么**：集中管理地物类型中文名、颜色、面积单位、告警级别等字典项，可配置。
- **作用**：现在这些硬编码在前后端多处，改一处要改多端。集中成字典后，客户可自定义，也便于后续扩展地物类型。
- **融入位置**：平台管理 → 新增「数据字典」页。
- **技术要点**：后端 dict 表 + 接口，前端替换硬编码的 classLabel/color 映射。

## 五、跨域增强（提升整体体验）

### 12. 全局搜索与快捷入口（P2）

- **做什么**：顶部导航加全局搜索框，输入关键词（矿区名、影像、告警、任务）快速跳转。
- **作用**：功能多了以后，找东西变慢。全局搜索是大型后台的标配，提升可用性。
- **融入位置**：顶部导航栏，加搜索框。
- **技术要点**：后端统一搜索接口（聚合 imagery/extractions/alarms/projects 的 name 字段），前端下拉联想。

## 建议实施顺序

1. **第一批（P0，先做，直接提升演示效果）**：多期对比热力图 + 变化检测自动预警

> 不引入新的重型依赖，demo 阶段可在当前 monorepo（Vue3 + Spring Boot + FastAPI）内全部完成。
