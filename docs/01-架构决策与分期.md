# 架构决策与分期（ADR-01）

> 版本：v1.0 ｜ 日期：2026-10-16 ｜ 状态：已确认（用户四项拍板）

## 一、已确认的四个关键决策

1. **后端栈：Java Spring Boot 3 + Python FastAPI 双服务**（按技术大纲）。业务与算法解耦，
   Java ↔ Python 走 REST 提交 + 回调。理由：交付给政企客户的企业级架构，也符合投标文档口径。
2. **第一里程碑：demo 优先**。先用 Sentinel-2 公开数据跑通全流程演示，向赣锋拿单后再按生产级补齐。
3. **算力：有 GPU 服务器**。解译训练/推理部署在 GPU 服务器；本机（i7-4790 / Quadro K2200）只做开发与前端调试。
4. **数据：暂无商业影像**。demo 阶段用 Sentinel-2（10m 多光谱，免费时序）跑通流程；亚米级影像采购到位后仅替换输入源与模型，不动平台链路。

## 二、架构决策（每条附一句话理由）

| # | 决策 | 理由 |
|---|---|---|
| 1 | monorepo，按服务分目录（frontend / backend-java / inference / deploy / docs） | 一个团队维护，比多仓库少联调成本 |
| 2 | Java 服务按功能分包（auth/project/file/task/result），控制器→服务→仓储三层 | 大纲既定模式，利于测试与演进 |
| 3 | 配置全部走环境变量 + .env，启动时集中校验 | 密钥不入库，环境可复现 |
| 4 | 认证：JWT 短时效访问令牌 + 刷新令牌（Redis 存） | demo 也要有像样的登录，令牌不落 localStorage |
| 5 | 实时：WebSocket 推送解译进度与传感器数据 | 比轮询省资源，Cesium 场景常驻连接 |
| 6 | 数据层 demo 期：PostGIS + MinIO + Redis + EMQX 单机 | TDengine/Kafka/Flink/K8s 是生产期扩展，demo 不背这个负担 |
| 7 | 前端 API 客户端：类型化 fetch 封装，Base URL 走 `VITE_API_BASE_URL` | demo 期不引入 React Query/tRPC，保持栈轻 |
| 8 | 解译 demo 算法：Sentinel-2 指数法（NDVI/NDWI/裸土指数）+ 阈值分割出七类雏形 | 无训练样本也能出结果；GPU 就位后换 Mask2Former 基线 |
| 9 | 变化检测：多期分类结果 GIS 叠加 + 类别转移矩阵（可解释基线） | 报告第六章既定路线，ChangeFormer/BIT 属第二阶段 |
| 10 | 预测模块：面积时序拟合（线性/Logistic）+ 边界扩张方向外推，输出不确定性说明 | 报告与大纲均无预测方案，这是补缺口；结论必须带置信说明 |
| 11 | 报告引擎：python-docx 模板化生成 docx，结论措辞由规则按数据生成 | 守住报告口径：「风险筛查 ≠ 实测侵蚀量」「复绿 ≠ 修复成功」 |
| 12 | IoT：预留 MQTT 接入 + 传感器点位模型，demo 用模拟数据推送 | 需求是「留好接口」，不接真设备 |

## 三、分期计划（demo 导向重排，替代大纲里的 5-7 个月排期）

| 阶段 | 内容 | 出口标准 |
|---|---|---|
| **S1 骨架** | 仓库结构 + docker-compose 基础设施 + 三个服务骨架可启动 | 三服务起得来，/health 通 |
| **S2 解译闭环** | Sentinel-2 下载 → 指数法分类 → GeoJSON 结果 → Java 回调入库 | 上传一景影像能出分类图 |
| **S3 三维演示** | Cesium 加载矿区底图 + 分类结果叠加 + 时间轴播放多期变化 | 能演示时序变化 |
| **S4 预测+报告** | 面积时序拟合预测 + 稳定性/安全性报告 docx 导出 | 一键出报告 |
| **S5 IoT 模拟** | 模拟传感器 MQTT 上报 → WebSocket 推前端 → 点位告警 | 大屏能看到模拟告警 |
| **S6 演示打磨** | 登录权限、界面打磨、演示脚本 | 可向客户演示 |

## 四、明确延后到生产期的内容

- Kafka / Flink / TDengine / Elasticsearch
- K8s 编排、蓝绿部署
- Mask2Former 训练与跨矿区泛化实验（依赖商业影像采购）
- RBAC 细粒度权限、审计日志、等保合规
- SAM2 辅助标注界面（线下用 CVAT/labelme 即可）

## 五、风险提醒（从报告继承）

1. 演示中的分类结果基于 Sentinel-2 10m 分辨率，**给客户演示时必须说清证据等级**，亚米级才是正式成果数据源。
2. 「预测」功能是趋势外推，不是实测——报告和界面上都要标注不确定性。
3. 生态与安全结论措辞按报告第七章口径走，防止过度解释。
