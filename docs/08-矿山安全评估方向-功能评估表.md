# 矿山安全评估方向 · 功能评估表

> 编制日期：2026-10-20
> 平台重新定位：**矿山地表变化监测 + 开采安全风险筛查**（物联网设备监测暂缓，仅作接口预留）
> 核心命题：能否用遥感手段，判断"这座矿山在安全地开采"——采坑边帮是否变陡、排土场是否失稳前兆、复绿是否真实、越界是否发生
> 需求基线：《赣锋锂业硬岩锂矿遥感监测综合分析报告与实施方案》表 6/7/8/12、第 6/7 章

## 一、核心思路：矿山安全评估的遥感可行路径

### 1.1 先明确一件事：遥感能做什么、不能做什么

| 层级 | 能否用遥感做 | 说明 |
|---|---|---|
| 地表形态变化（坑扩、堆高、塌陷） | ✅ 可以 | 亚米级影像 + DSM 差分，这是核心能力 |
| 边坡几何指标（坡角、坡高、坑深） | ⚠️ 有条件可以 | 必须亚米级 DSM；30m 公开 DEM 做不到 |
| 边坡稳定性计算（安全系数 Fs） | ❌ 不能 | 需岩土参数、地下水、结构面产状，属岩土工程 |
| 形变速率（mm/年） | ⚠️ 需 InSAR | Sentinel-1 时序处理，成本高但可行 |
| 越界开采 | ✅ 可以 | 采坑边界 vs 矿权边界叠加 |
| 水土流失风险 | ✅ 可分级 | 多因子相对分级，不能报侵蚀量 |

**结论**：平台能给出的是**"潜在安全风险筛查"**——哪里形态异常、哪里变化过快、哪里越界、哪里覆盖恶化，供现场核查；**不能给"该边坡稳定/不稳定"的结论**。这条边界必须写进产品说明，否则现场必被追问穿。

### 1.2 数据前提（决定了能做到什么精度）

| 数据类型 | 来源 | 能支撑的指标 | 局限 |
|---|---|---|---|
| **公开 DEM 30m**（Copernicus GLO-30 / ALOS AW3D30） | 免费，可立刻接入 | 区域坡度、坡向、汇流累积、地形起伏 | 单个矿坑直径 500–1500m、深 100–300m，30m 像元把边坡细节全部抹平，**算不出台阶坡面角** |
| **无人机航测 DSM**（1–5cm） | 客户现场作业 | 坑深、边坡角、台阶高度、体积、DEM 差分 | 需现场配合，demo 阶段无数据 |
| **亚米级立体像对**（GF-7 / Pléiades） | 商业采购 | 同上（摄影测量生成 DSM） | 需采购 + 摄影测量处理 |
| **Sentinel-1 InSAR** | 免费 | 形变速率 mm/年（边坡蠕变、排土场沉降） | 需时序 SAR 处理链（SNAP/StaMPS），技术门槛高 |
| **Sentinel-2 多光谱** | 免费 | 植被覆盖度、水体、裸地、变化检测 | 10m 分辨率，只能看大尺度 |

### 1.3 安全风险评估指标体系（四层融合）

这是"把植被覆盖、水体覆盖、形态变化融到一起判断"的具体做法——**多因子加权风险评价**。

#### A 层：形态因子（几何风险，需 DSM）
| 因子 | 计算 | 风险方向 | 数据要求 |
|---|---|---|---|
| 边坡角 | arctan(坑口到坑底高差 / 水平距离) | 越陡越危险（终了边坡角通常 40–50°） | 亚米级 DSM |
| 边坡高度 | 坑口高程 − 坑底高程 | 越高越危险 | 亚米级 DSM |
| 台阶坡面角 | 单台阶坡面倾角 | 超陡即失稳前兆 | 亚米级 DSM（30m 不可行） |
| 坡度变化率 | 两期坡度图相减 | 变陡 = 风险上升 | 两期 DSM |
| 采坑体积 | DEM 差分积分 | 挖方量、超采判断 | 两期 DSM |

#### B 层：地表覆盖因子（生态与水文风险，Sentinel-2 即可）
| 因子 | 计算 | 风险方向 |
|---|---|---|
| 植被覆盖度 FVC | 由 NDVI 反演（像元二分模型） | 低覆盖 = 水土流失风险高 |
| 裸地占比 | 裸地面积 / 矿区面积 | 高 = 扬尘、侵蚀风险 |
| 坑内积水面积 | 水体掩膜 ∩ 采坑范围 | 扩大 = 排水不畅、突水风险 |
| 尾矿库水面变化 | 水体掩膜 ∩ 尾矿设施范围 | 水位上升 = 溃坝风险预警 |
| 复绿速率 | 连续 3 期以上植被信号恢复 | 正向指标（但≠修复成功） |

#### C 层：空间关系因子（合规与连锁风险）
| 因子 | 计算 | 风险方向 |
|---|---|---|
| 越界开采 | 采坑边界 − 矿权边界 的面积 | 有越界即重大违规 |
| 采坑–生态红线距离 | 空间距离计算 | 越近风险越高 |
| 排土场是否位于汇流路径 | 汇流累积栅格 ∩ 排土场 | 位于沟谷汇流 = 泥石流风险 |
| 道路切坡 | 道路 ∩ 坡度 > 25° 区域 | 切坡路段 = 滑坡风险 |

#### D 层：变化速率因子（时序风险）
| 因子 | 计算 | 风险方向 |
|---|---|---|
| 采坑扩张速率 | 面积增量 / 时间（ha/年）或边界推进（m/年） | 突增 = 超计划开采 |
| 排土场堆高速度 | 体积增量 / 时间 | 快速堆填 = 稳定性风险 |
| 扰动新增速率 | 新增扰动并集面积 / 时间 | 突增 = 管控失序 |

### 1.4 风险输出方式（必须是"可解释"的，不能只给一个总分）

1. **风险分级栅格图**：把四层因子归一化后加权 → 5 级（低/较低/中/较高/高）→ 生成专题图叠加到三维地球
2. **风险热点清单**：每处热点给出——位置、面积、涉及因子、各因子实测值、证据影像日期、建议核查方式
3. **趋势研判**：同一区域多期风险等级变化（升级/持平/降级）

> 设计原则：客户要的不是"85 分"，而是"**哪块地危险、为什么危险、我该去看什么**"。

## 二、关键技术判断（避免过度承诺）

### 2.1 30m 公开 DEM 能干什么、不能干什么

| 能 | 不能 |
|---|---|
| 区域地形背景（矿区整体起伏） | 矿坑边坡角（像元 30m vs 边坡细节 m 级） |
| 坡度/坡向/地形起伏度 | 台阶高度与坡面角 |
| 汇流累积 → 排土场选址风险 | 坑深（坑宽仅十几到几十像元，且深度变化小于 DEM 垂直精度） |
| 生态缓冲区的地形因子 | 体积计算（垂直误差 ±5–10m，体积误差巨大） |

**落地建议**：demo 阶段用 30m DEM 只做**汇流/坡度背景**，明确标注"精细边坡指标需无人机或立体像对"；采坑形态改用**二维指标**（面积、周长、形状指数、边界推进速度）替代。这样既专业又不虚。

### 2.2 二维形态指替代方案（无需 DSM 即可做，客户也看得懂）

| 指标 | 计算 | 意义 |
|---|---|---|
| 采坑面积 / 周长 | 矢量化直接得 | 基础量 |
| 形状指数 | 4πA / P² | 越接近 1 越圆；不规则化 = 多方向扩张 |
| 边界推进速度 | 两期边界间平均距离 / 时间（m/年） | 替代"扩张速率"，比面积更直观 |
| 边界凸出度 | 新增区域沿法向外凸的距离 | 识别"向某方向突进"的超采迹象 |
| 最小外接矩形长宽比 | 采坑方向性 | 判断推进主轴 |

## 四、功能闭环关系（关联逻辑）

```
影像获取（Sentinel-2 / 亚米级 / 无人机）
   ↓
七类地物提取 ──→ 采坑边界 ──→ 二维形态指标（面积/周长/推进速度）
   │                │              ↓
   │                └──────→ 越界检测（∩ 矿权边界）
   │                               ↓
   ├─→ 植被覆盖 FVC ──┐            │
   ├─→ 水体（坑内积水）├─→ B 层覆盖因子
   ├─→ 裸地占比  ────┘            │
   │                               ↓
DEM/DSM ──→ 坡度·汇流 ──→ A 层形态因子 ──→ 【多因子风险模型】──→ 5 级风险图 + 热点清单
   │                               ↑                        │
   └─→ 排土场汇流风险 ─────────────┘                        ↓
                                                     安全评估报告章节
时序数据 ──→ 扩张速率/复绿速率 ──→ D 层变化因子 ──────────┘
                                                          ↓
                                                  风险升级 → 告警闭环
```

**关键关联点（客户最容易感知的三条）**：
1. **采坑扩张速度 + 越界** → "有没有超计划、超范围开采"
2. **植被覆盖下降 + 裸地增加 + 坡度大** → "水土流失高风险区在哪"
3. **坑内积水扩大 + 边坡变陡** → "排水是否失效、边帮是否危险"

## 六、口径红线（必须写进产品与报告）

1. 输出为「**潜在安全风险筛查**」，不是边坡稳定性评价，不给安全系数
2. 不使用"该边坡稳定/不稳定"表述，只用"形态指标异常，建议现场核查"
3. 30m DEM 不得用于计算台阶坡面角、坑深、体积；相关指标必须标注数据来源与精度
4. 水土流失只给**相对风险等级**，不报侵蚀量（t/ha）
5. 「持续复绿」≠「生态修复成功」，需现场资料与修复目标佐证
6. 采坑边界由影像解译得到，与**矿权审批边界**是两个对象，越界判定须注明双方来源与日期
7. 所有风险结论必须附：因子实测值、影像日期、传感器类型、证据等级

## 七、与现有平台的衔接

已具备、无需重做的基础：
- 七类地物提取（本地解译全支持，在线缺 4 类 → E1 补齐）
- 存量口径时序统计（同区域同期取最新，不累加）
- 空间求差热力图（新增/消失区）
- 单区域体检（全类型历年变化）
- 矿权/扰动/生态红线三图层（B5 越界检测可直接复用）
