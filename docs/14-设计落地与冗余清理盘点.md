## 一、本轮新增（已落地）

### 1. 侧边栏按工作阶段分组（替代原来的平铺）
原来每个模块只有一组、所有页面平铺；现在按"准备数据 → 执行作业 → 看结果 → 出成果"归类，分组标题可点击折叠。

| 模块 | 分组 |
|---|---|
| 遥感解译 | 数据准备（影像库、边界管理）· 解译作业（在线解译、本地解译）· 结果比对（数据对比） |
| 监测告警 | 监测数据 · 站点与规则 · 告警处理 |
| 报告中心 | 变化分析 · 安全与生态评估（4 项）· 成果输出 |
| 平台管理 | 组织与权限 · 系统运维 |

### 2. 边界导入（docs/12 阶段一，此前只有设计没有代码）

| 环节 | 实现 |
|---|---|
| 解析 | `inference/aoi_import.py`：SHP（zip 四件套 / 单 shp）、GeoJSON、KML/KMZ |
| 坐标系 | rasterio `CRS.from_wkt` + `warp.transform`，**不引 pyproj**；`.prj` 缺失且坐标不像经纬度 → 直接报错，不猜 |
| 多要素 | 默认一个要素一条记录，可勾选合并 |
| 内洞 | 保留，面积按外环减内洞计算 |
| 落库 | 新表 `aoi_boundary`（projectId / boundaryType / geometryJson / areaHa / sourceCrs / warnings） |
| 页面 | `BoundaryView`（/boundary）：导入、列表、SVG 预览、「用于提取」 |
| 与越界检测联动 | `SafetyController` 优先取 `aoi_boundary` 的 PERMIT 环，退回 `project.boundaryJson`，返回值新增 `permitSource` 标注来源 |
| 与提取页联动 | 「用于提取」写入 `pending_aoi` → 在线解译页自动载入并飞到范围；提取页边界图层同时叠加导入的边界 |

实测：UTM 50N 的矿权 zip 导入 246.74 ha、5 顶点、`EPSG:32650`；越界检测 `available=true`。

### 不删、但有重叠要说明的

- **在线解译 vs 本地解译**：数据源不同（公开 Sentinel-2 / 用户上传高分影像），不是重复，保留。
- **数据对比（CompareView）vs 提取页变化对比**：前者比影像，后者比解译图斑变化，能力不同但入口重复 → 应合并入口而非删功能。

## 六、建议顺序

1. **清理冗余**（半天）：RemoteExtractView 拆出"批量时序提取"独立页；比对类功能合并到 CompareView；处理 tasks 死链路（待确认）

6. **E2 元数据 + E6/E7 文档**（2–3 天）：纯交付物，交付前补

## 七、口径红线（不因功能增加而放宽）

- 一切结论仍是「潜在安全风险筛查」，不给边坡稳定性结论、不给安全系数
- 10m DEM 不用于台阶坡面角/坑深/体积
- 水土流失只给相对风险等级，不报侵蚀量
- 导入的边界是「矿权/项目范围」，与「实际扰动边界」分开存、分开用
