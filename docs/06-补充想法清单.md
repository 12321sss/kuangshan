## 一、面向拿单的杀手级功能（清单缺的）

### 1. 一键演示剧本（Demo Script）—— P0

- **做什么**：预设一条 3 分钟叙事路径，点一次"开始演示"自动依次走完：矿区概况 → 圈 AOI → 解译出结果 → 3 年时序动画 → 弹热力图 → 生成报告。
- **作用**：客户坐下后不用手忙脚乱操作，点一下整条链路自动播放。给演示兜底，避免现场"点到哪算哪"。
- **融入位置**：新增"演示模式"入口（总览页或顶栏），内部复用各页面的既有动作序列。
- **技术要点**：前端一个脚本化的步骤序列（顺序触发圈选/提取/播放/报告接口），不做后端改动；可加"跳过/暂停"控制。

### 2. 三维驾驶舱首页 —— P0

- **做什么**：把 Cesium 三维 + 传感器点位 + 解译结果 + 告警热区叠进一个"一眼看懂整个矿区"的驾驶舱首页，右上角悬浮关键 KPI。
- **作用**：客户第一眼看到的东西，直接定调"这是高级货"。现在的总览是卡片式，缺三维冲击力。
- **融入位置**：总览页重构，或新增独立"驾驶舱"页设为登录后首页。
- **技术要点**：复用 ScreenView 的三维底图 + 传感器点位 entity + 解译多边形叠加，KPI 用悬浮卡片。

### 3. 单 AOI 纵向"体检"报告 —— P1

- **做什么**：圈一块地，一次输出这块地"每一类地物历年面积变化曲线 + 当前构成饼图"，像给矿区做全面体检。
- **作用**：现有对比是"同类跨年"，缺"同块地全类型"的纵向维度。客户问"这块地到底怎么回事"，一个页面答完。
- **融入位置**：变化分析页新增"单区体检"tab。
- **技术要点**：复用 TimeSeriesController 的分组逻辑，跨类型聚合，前端 echarts 多序列曲线 + 饼图。

### 4. 矿权边界合规图层 —— P0

- **做什么**：把矿权红线、实际扰动边界、生态红线叠成三个可开关图层。
- **作用**：呼应实施方案红线"矿权边界 ≠ 扰动边界"，专业性 + 合规意识。国企客户很吃这套。
- **融入位置**：GIS 大屏 + 遥感提取页，加图层开关。
- **技术要点**：后端存矿权/扰动边界 GeoJSON（可先手工录入样区），前端 Cesium 三个 entity 图层。

## 二、已有功能的专业深度（优化清单没提到的）

### 5. 解译结果置信度标注 —— P1

- **做什么**：提取完标注"证据等级"（10m Sentinel-2 = 等级 B，亚米级商业影像 = 等级 A）。
- **作用**：呼应红线"必须向客户说清证据等级"，防止客户拿 10m 结果当亚米级用，回头扯皮。
- **融入位置**：提取结果面板 + 报告，加一个等级徽标。
- **技术要点**：前端按 satellite 字段映射等级，报告 report.py 加一行说明。

### 6. 云量/遮挡提示 —— P1

- **做什么**：拉景时若云量偏高，结果面板加黄色提示"本期云量 15%，解译结果可能受云影响"。
- **作用**：比事后解释强，让客户理解结果边界。
- **融入位置**：提取结果面板 + 影像检索结果。
- **技术要点**：前端已拿到 cloud_cover 字段，按阈值显示提示即可，无后端改动。

### 7. 时序数据缺口可视化 —— P2

- **做什么**：矿区某几个月无无云影像时，时间轴用灰段标出"数据缺口"。
- **作用**：客户看到"为什么 2023 年没点"能立刻理解，不会以为系统漏采。
- **融入位置**：时序播放时间轴。
- **技术要点**：前端按相邻期日期差 > 阈值时插灰段。

## 三、工程健壮性（演示前必须补，清单基本没提）

### 8. 离线演示数据包 —— P0（最高）

- **做什么**：预先把目标矿区的影像 + 解译结果 + 时序缓存到本地，断网也能完整走一遍演示。
- **作用**：本机依赖在线拉景（且沙箱代理限速），演示现场网络抽风就全崩。这是防翻车的底线，比任何新功能都重要。
- **融入位置**：新增"演示数据包"一键载入（替代现场圈选/下载）。
- **技术要点**：复用 inference 已有的 tile 级缓存（.cache），预下载目标矿区所有波段 + 预存解译结果 JSON；前端"载入演示数据"跳过在线检索。

### 9. 操作回滚/误删保护 —— P2

- **做什么**：解译记录、影像等做软删除 + 回收站，误删可恢复。
- **作用**：演示时手滑删一条记录就尴尬了。
- **融入位置**：各删除操作加软删除 + 平台管理加"回收站"页。
- **技术要点**：表加 deleted 标记位，删除改 update；回收站页可恢复/彻底删除。

### 10. 依赖健康面板 —— P1

- **做什么**：小页面实时显示 MySQL / inference / 天地图 / AWS STAC 四个依赖是否在线。
- **作用**：演示前扫一眼就知道今天能不能顺利演，不用等点按钮才发现挂了。
- **融入位置**：平台管理新增"系统健康"页，或顶栏小图标。
- **技术要点**：后端加 /api/health/checks 聚合探测四个依赖，前端绿红点展示。

## 实施建议（结合三份清单统一排序）

**第一优先级（P0，12 月前必须到位）：**
- 本清单：离线演示数据包（8）、矿权合规图层（4）、一键演示剧本（1）、三维驾驶舱（2）
- 原 04：多期对比热力图、变化检测自动预警
- 原 05：遥感提取向导化、分阶段加载、错误提示友好化、AOI 订阅、成果导出

**第二优先级（P1）：** 单 AOI 体检、置信度、云量提示、健康面板、告警闭环、传感器大屏、报告模板、操作日志……

**第三优先级（P2）：** 数据缺口、回收站、批量处理、访客分享、移动端、数据字典……

> 核心原则不变：**先做"客户能感知、演示能用上、能防翻车"的**，再做"内部完善"的。
> 其中"离线演示数据包"与"矿权合规图层"是本清单最该优先的两块——一个保命、一个加分。
