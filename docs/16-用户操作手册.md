# 用户操作手册

> 面向：矿区监测业务人员、解译分析师、项目管理员
> 平台：智慧矿山（遥感解译 + 安全监测）
> 所有分析结论均为**潜在风险筛查**，不构成稳定性评价、不给安全系数

---

## 一、首次使用（5 分钟跑通）

1. **登录**：默认管理员 `admin / admin123`（首次登录后请改密码）
2. **选工程**：右上角工程下拉框，所有页面的数据都按当前工程过滤
3. **导入边界**：遥感解译 → 数据准备 → **边界管理** → 选「矿权范围」→ 拖入 SHP 压缩包 → 解析并导入
4. **查影像**：遥感解译 → 解译作业 → **在线解译** → 点选边界或「复用上次 AOI」→ 查影像 → 提取 → 保存
5. **看结论**：报告中心 → 安全与生态评估 → **综合安全评估** → 开始评估

## 二、按角色看该用哪些页

| 角色 | 主要页面 | 关键动作 |
|---|---|---|
| 监测业务人员 | 总览、变化监测、安全评估、报告生成 | 每周查影像可用性、看突变点位、导出报告 |

## 三、边界管理（SHP 导入）

**进入**：遥感解译 → 数据准备 → 边界管理

1. **选用途**（必选，决定能被哪些功能用）
   - 矿权范围：登记数据，**越界开采检测只认这一类**
   - 实际扰动边界：影像解译得到的地表扰动范围，不能当矿权用
   - 生态缓冲区：用于矿区内外对比统计
2. **拖文件**：支持 `.zip`（含 shp+shx+dbf+prj）、`.shp`、`.geojson`、`.kml/.kmz`
   - 强烈建议打包 zip：单传 `.shp` 会缺坐标系与属性
3. **点「解析并导入」**：成功后显示格式、源坐标系、要素数、总面积、提示信息
4. **点「预览」**：看形状与面积是否正确
5. **点「用于提取」**：自动跳到在线解译页，把该边界当 AOI 并飞到范围

**常见问题**

| 现象 | 原因 | 处理 |
|---|---|---|
| 报「缺少 .prj 且坐标值不在经纬度范围」 | 坐标系文件丢了 | 把 `.prj` 一起打包；或先在 ArcGIS/QGIS 里转成 WGS84 |
| 面积明显偏大/偏小 | 坐标系选错或边界含内洞 | 看预览与源坐标系；内洞会自动扣除 |
| 一个矿权导入成多条 | 文件里有多个要素 | 勾「合并为一个范围」，或逐条保留分别管理 |

## 四、在线解译（快速模式）

**进入**：遥感解译 → 解译作业 → 在线解译

1. 圈选 AOI（或「复用上次 AOI」/ 从边界管理「用于提取」过来）
2. 「查询影像」：选日期范围与云量，平台自动挑云量最低的一景
3. 选地物类型（七类：露天采坑 / 排土场 / 尾矿 / 裸地扰动 / 植被 / 道路 / 水体），调阈值与最小面积
4. 「开始提取」→ 结果作为矢量图层叠加在地图上，可调颜色与透明度
5. 「保存」：一条记录一类地物，进入时序、风险、报告链路

**提示**
- 提取结果为 0 时先看诊断说明：可能该区域确实没有该类地物，也可能是阈值偏严
- 演示用 Sentinel-2 是 10m，边界锯齿明显；正式成果需亚米级影像

## 五、监督分类（精细模式，能出精度指标）

**进入**：遥感解译 → 解译作业 → 监督分类

1. **选分析区**：下拉里是「边界管理」导入的边界（没有就去先导入）
2. **选日期与云量** → 点「加载影像」，等真彩图出现（首次 20–60 秒）
3. **选类别 → 在图上点样本**
   - 左键点选，滚轮缩放，右键拖动平移
   - 每类 20–40 个，**分散在各类图斑各处**，不要全挤在一处
   - 避开混合像元（图斑边缘 2–3 个像元）
4. **点「开始监督分类」**（首次 1–4 分钟，之后有缓存会快）
5. **看精度**：总体精度 OA、Kappa、混淆矩阵、各类用户精度/制图精度
6. **点「保存为解译记录」**：每类落一条记录，后续可做时序与风险评估

**怎么判断结果能不能用**

| 指标 | 可用 | 需谨慎 |
|---|---|---|
| OA | ≥ 85% | < 75% 建议重选样本 |
| Kappa | ≥ 0.8 | < 0.6 说明类别间光谱重叠严重 |
| 某类用户精度 | ≥ 80% | < 60% 该类不可用于对外结论 |

**注意**：训练/验证是 65:35 分层抽样，验证集不参与训练；样本太少（每类 <8）会拒绝运行，且不做拆分时 OA 会偏高。

## 六、变化监测（周尺度）

**进入**：遥感解译 → 持续监测 → 变化监测

### ① 影像可用性检查

选分析区 → 设置「往前看 N 天」→ 检查。结果会明确告诉你：

- 有几天可用影像、最近一期是哪天
- 若没有：是「完全没影像」还是「有影像但云太多」（后者可放宽云量重试）

**记住**：**「没有可用影像」不等于「没有变化」**，页面会分开说明。

### ② 两期突变检测

1. 选两期日期范围（建议间隔 ≥15 天，太短噪声多）
2. 最小斑块默认 0.5 ha；调到 0.1 会多出大量抖动点
3. 点「开始检测」，得到四类事件：新增水体 / 水体消失 / 新增裸地扰动 / 植被恢复
4. 每类给出处数、总面积与点位（可复制坐标到现场核查）
5. 底部变化图上颜色与事件对应

**为什么要设 0.5 ha**：10m 影像一周内采坑只推进 0.4–1 m（不到 1/10 像元），小斑块基本是阈值抖动。

## 七、空间关系与专项风险

**进入**：报告中心 → 安全与生态评估 → 空间关系

点「开始分析」后得到 6 张卡片，每张给「结论 + 指标 + 建议核查方式」：

| 卡片 | 看什么 |
|---|---|
| 坑内积水 | 水体占采坑比例 ≥15% → 排水可能失效 |
| 尾矿库水面 | 较上期扩大 ≥20% → 核查库水位与排渗 |
| 排土场汇流 | 压占低洼汇水区 ≥25% → 查截排水与拦挡 |
| 道路切坡 | 陡坡段占比 ≥20% → 查边坡支护 |
| 生态缓冲区 | 缓冲区与矿区内植被差 → 扰动是否外扩 |
| 采坑形态 | 形状指数（1=正圆）、等效半径推进 |

卡片标「不可用」是在告诉你**数据不足**（如"尚未提取采坑"、"植被只覆盖缓冲区 24%"），不是系统故障。专题图可「下载 PNG」放进汇报材料。

## 八、综合安全评估与报告

**安全评估**：报告中心 → 综合安全评估 → 勾「用边坡单元细化形态评估」（多 10–30 秒）→ 开始评估

- 总分 + 等级 + 六维得分（形态/扩张/越界/覆盖/水文/生态）
- 每维都列「证据数值 + 建议」。可信度标「低」的维度说明数据不足
- 越界检测只在导入过**矿权范围**后可用

**生成报告**：报告中心 → 成果输出 → 报告生成 → 勾「包含安全风险评估章节」→ 生成 Word

## 九、影像档案元数据（合规答复用）

**进入**：遥感解译 → 数据准备 → 影像库 → 操作列「元数据」

12 项：离轴角、太阳高度角/方位角、正射等级、**授权范围**、供应商、价格、币种、采购单号、交付日期、波段数、传感器。

- **授权范围**决定这批影像能不能用于模型训练、能否对外发表、能否跨境传输，客户审计必查
- 留空表示未登记，不代表"无限制"
- 非法值会被拦下（如离轴角 99°）

## 十、数据安全

- 删除解译记录 → 进**回收站**（回收站页可还原或彻底删除），演示现场误删不会丢数据
- 删影像前会提示关联了多少条解译记录，一并移入回收站
- 所有删除/还原/导入动作都写入操作日志

---

## 十一、口径红线（对客户必须这样说）

1. 平台输出的是「**潜在水土流失 / 安全风险筛查**」，不是实测侵蚀量，不给安全系数
2. 「**持续复绿**」仅表示植被覆盖回升，**不等于生态修复成功**
3. 10m 公开影像**不能**算台阶坡面角、坑深、采坑体积；正式成果需亚米级 DSM
4. 矿权边界 ≠ 实际扰动边界，两者分开管理、分开表述
5. 监督分类的 OA/Kappa **只对本 AOI 本景有效**，不能外推到其它矿区

## 十二、常见问题

| 问题 | 处理 |
|---|---|
| 点页面报 `does not provide an export named ...` | 前端依赖缓存异常：Ctrl+F5 硬刷；仍报错则重启 `npm run dev` |
| 分析卡在"加载中" | 首次要下载影像瓦片（1–4 分钟），看后端日志确认在下载 |
| 报"目标计算机积极拒绝" | 解译服务没起：确认 8010 端口在监听 |
| 评估里某项「可信度 低」 | 该项所需数据不足（期数/地形/边界），补数据后再看 |
| 越界检测显示不可用 | 项目没导入「矿权范围」边界 |
| 报告缺安全章节 | 生成时没勾「包含安全风险评估章节」 |
