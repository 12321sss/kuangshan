# 智慧矿山平台 · 客户操作功能扩展 & 已有功能优化清单

> 版本：2026-10-20
> 定位：承接 `04-功能扩展清单.md`，重点补两类内容——
> ① **客户可主动操作的功能**（现在平台基本是「被动看」，缺「上手用」的能力）
> ② **已有功能的优化点**（让现有功能更好用、更专业、更抗演示现场发问）

---

## 第一部分：客户操作类新功能（8 个）

> 设计视角：客户登录后，除了看数据，**还想自己动手做什么**。
> 核心是「让客户有掌控感」——能圈、能查、能导、能定、能收通知。

### 1. 自定义 AOI 监测订阅（P0）

- **做什么**：客户在地图上圈定一块关注区域（AOI），保存为「我的关注区」，系统定期自动拉最新影像解译，把该区域的变化结果推给客户。
- **作用**：客户最核心的操作诉求——「我就关心我那块地，有变化通知我」。从「我每次手动圈」变成「圈一次、持续盯」。这是最能打动客户的主动性功能。
- **融入位置**：遥感提取页加「保存为关注区」按钮；总览页加「我的关注区」卡片。
- **技术要点**：
  - 后端新增 `aoi_watch` 表（projectId/userId/aoiJson/签名/创建时间/上次检查时间）
  - 定时任务对每个关注区跑在线解译，与上次结果做 diff，有显著变化则生成告警/通知

### 2. 成果一键导出（GeoTIFF / GeoJSON / Shapefile）（P0）

- **做什么**：客户把解译结果（矢量多边形）导出为 GeoJSON / Shapefile，把 AOI 影像导出为 GeoTIFF，用于自己的 GIS 软件（ArcGIS/QGIS）二次处理。
- **作用**：客户要拿数据走、做自己的分析，这是硬需求。现在平台结果「关在网页里」，导不出来就留不住客户。
- **融入位置**：遥感提取页结果面板、影像库、变化分析页，加「导出」按钮。
- **技术要点**：
  - GeoJSON 导出：前端直接把 features 序列化下载（最简单）
  - Shapefile/GeoTIFF：inference 用 rasterio/pyshp 生成，返回文件流
  - 优先做 GeoJSON + GeoTIFF，Shapefile 视需求

### 3. 告警订阅与通知（P1）

- **做什么**：客户可选择关注哪些告警类型（位移超限、遥感变化、水位异常），告警发生时站内通知 + 可选邮件推送。
- **作用**：客户不想每天登录看，只想「出事了告诉我」。订阅通知是留客的关键。
- **融入位置**：顶部导航加「消息中心」铃铛；预警设置页加订阅开关。
- **技术要点**：
  - 后端新增 `notification` 表（userId/type/content/read/时间）
  - 站内通知：轮询或 WebSocket；邮件推送 demo 期可用 agent-mail 预留

### 4. 影像收藏与快速定位（P1）

- **做什么**：客户可收藏常用影像/常用矿区坐标，下次一键定位、快速复用。
- **作用**：减少重复操作。客户每次演示都圈同一块地，收藏后点一下就到。
- **融入位置**：影像库加收藏星标；总览加「最近访问」快捷入口。
- **技术要点**：前端 localStorage 或后端 `favorite` 表（视是否跨设备）

### 5. 数据对比工具（双屏/滑块对比）（P1）

- **做什么**：客户把两期影像或两期解译结果并排（或滑块拖动）对比，直观看到前后差异。
- **作用**：比「叠加热力图」更直观的对比方式，客户演示时很好用。
- **融入位置**：变化分析页加「对比模式」切换（并排 / 滑块）。
- **技术要点**：Cesium 双 viewer 或单 viewer 分屏；滑块对比用 CSS clip 裁剪叠加层

### 6. 自定义报表模板（P1）

- **做什么**：客户可配置报告的封面信息（单位名、logo、负责人）、选择要包含的章节、设置报告周期。
- **作用**：报告能带上客户自己的单位信息，交付感更强，客户更愿意用。
- **融入位置**：报告中心 → 报告生成页，加「模板配置」。
- **技术要点**：后端 `report_template` 表存客户自定义配置，inference 生成时读入

### 7. 批量影像处理（P2）

- **做什么**：客户一次性上传多张影像 / 对多个 AOI 批量跑解译，任务排队后台执行。
- **作用**：客户要处理一整片矿区（多景影像），一个个点太慢。批量是效率刚需。
- **融入位置**：影像库加「批量上传」；解译加「批量任务」。
- **技术要点**：复用现有任务队列机制（_tasks），加批量提交入口

### 8. 权限下放的「访客分享」（P2）

- **做什么**：客户可生成一个只读分享链接，把某个项目的数据视图（含地图、报告）分享给未登录的第三方（如领导、合作方）。
- **作用**：客户要给别人看结果，但不想开账号。分享链接是最轻量的方式。
- **融入位置**：项目管理加「生成分享链接」。
- **技术要点**：后端生成带 token 的只读链接，前端 `/share/:token` 只读页面（复用 ScreenView 精简版）

## 第二部分：已有功能优化点（10 个）

> 视角：让现有功能「更好用、更专业、更抗演示现场发问」。

### 1. 遥感提取交互优化（P0）

- **现状**：圈 AOI → 查询影像 → 提取 → 保存，四步割裂，新用户不知道先点哪个。
- **优化**：做成「向导式」流程，顶部步骤条（1 圈范围 → 2 选影像 → 3 提取 → 4 保存），每步高亮当前、禁用未到步骤。加「下一步」按钮串联。

### 2. 加载体验优化（P0）

- **现状**：在线拉景首次要 1-3 分钟，期间只有转圈，用户以为卡死。
- **优化**：加**分阶段进度提示**（检索中 → 下载波段中 → 计算指数中 → 矢量化中），显示当前阶段和预估剩余时间；首屏加「正在从 AWS 拉取卫星影像，首次较慢，之后有缓存」的说明。

### 3. 错误提示友好化（P0）

- **现状**：后端报错直接弹英文/堆栈（如 422、500），客户看不懂。
- **优化**：统一错误码 → 中文友好提示（如「该区域近期无云影像，请放宽日期或云量阈值」）。后端 BizException 已有中文 message，补前端统一的错误拦截。

### 4. 空状态引导（P1）

- **现状**：无数据页面一片空白或只写「暂无数据」，客户不知道下一步干嘛。
- **优化**：每个空状态加「去做什么」的行动按钮（如影像库空 → 「去上传影像」按钮；分析页空 → 「去遥感提取」按钮）。

### 5. 时间轴体验（P1）

- **现状**：时序播放是「帧跳变」，不够流畅。
- **优化**：加平滑过渡（Cesium 补间动画或 requestAnimationFrame 渐变），时间滑块加刻度标注日期。

### 6. 地图底图与性能（P1）

- **现状**：低配机器（Quadro K2200）跑 Cesium 可能卡，底图只有天地图/高德。
- **优化**：加底图自动降级（检测性能自动降低分辨率）、默认关闭不需要的高耗能特效（如阴影、抗锯齿按需开）。

### 7. 移动端适配（P2）

- **现状**：纯桌面布局，手机上打开错乱。
- **优化**：至少总览页 + 告警页做响应式，客户在手机上能看关键指标和告警。

### 8. 数据一致性校验（P1）

- **现状**：删除影像后，关联的提取记录还在，出现「孤儿数据」。
- **优化**：删除影像时级联处理关联提取记录，或软删除 + 提示。后端加外键约束/逻辑校验。

### 9. 演示模式（P2）

- **现状**：每次演示都要现场圈 AOI、等下载，容易出意外。
- **优化**：内置「演示数据包」——预置一个矿区的完整时序数据 + 解译结果，一键载入，演示时点开即看，不用现场操作。

### 10. 国际化/单位统一（P2）

- **现状**：面积已统一 km²，但部分文案、日期格式不统一。
- **优化**：统一日期格式（YYYY-MM-DD）、数字千分位、百分比位数，全站一致。

## 建议实施顺序（结合上一份清单）

1. **第一批（P0，最能打动客户 + 防演示翻车）**
   - 客户操作：自定义 AOI 监测订阅、成果一键导出
   - 已有优化：遥感提取向导化、分阶段加载进度、错误提示友好化
   - 承接上份清单的 P0：多期对比热力图、变化检测自动预警

2. **第二批（P1）**：告警订阅、影像收藏、数据对比、报表模板 + 空状态、时间轴、底图性能、数据一致性

3. **第三批（P2）**：批量处理、访客分享、移动端、演示模式、单位统一

> 原则：**先做「客户能感知、演示能用上」的**，再做「内部完善」的。
