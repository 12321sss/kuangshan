# 2026-10-30

## inference 目录工程化重构（去"脚本缝合"痕迹）

### 起因
用户指出 `inference/` 里有 20 多个 `patch_xxx.py` / `fix_upload.py`，"是一路缝出来的痕迹，
能跑但维护成本很高"，要求整理成完整项目的样子。

### 做过的改动
1. **`main.py` 1488 行 → 3 行**。28 个端点按 URL 前缀拆进 `app/routers/` 14 个文件
   （system / extraction / sentinel / terrain / risk / slope / classification /
   monitor / spatial / boundary / imagery / fusion / report / ecology）。
   切片搬原文 + 机械替换，逻辑零改动。
2. **新增 `app/` 应用层**：`config.py`（环境变量集中）、`logging_setup.py`（替代 print）、
   `middleware.py`（请求 ID + 耗时）、`tasks.py`（任务表 + 回调）、`geo.py`（AOI 工具）、
   `schemas.py`（共用模型）、`__init__.py`（create_app）。
3. **15 个算法模块搬进 `algorithms/`**，包内互引用改相对导入（`from . import dem`）；
   新增 `algorithms/paths.py` 统一缓存目录。
4. **7 个 selftest → `scripts/selftest/`**，2 个 probe → `scripts/`，删除 `_t/` 全部 22 个补丁脚本。
5. **新增 `tests/`（pytest 23 个用例）**：契约护栏 + 融合/边界/报告/影像识别/本地分类/任务表。
6. **工程文件**：`README.md`、`.env.example`、`pyproject.toml`（pytest+ruff）、
   `requirements-dev.txt`；`requirements.txt` 补 Pillow/affine 并锁版本。

### 顺带修的真实缺陷（不是风格问题）
- **报告第九章附录永远为空**：`ReportRequest` 漏声明 `extractions`，Pydantic 静默丢弃。
- **requirements 漏 Pillow**（PIL 用了 14 处）、漏声明 affine。
- **affine 3.0 弃用 `*`**：`supervised_local.py` 两处改 `@`。
- **搬迁会让瓦片缓存路径变化**：sentinel 用 `__file__` 现算 `.cache`，挪包后 150MB 预热全废 →
  改读 `paths.CACHE_DIR` 且保持 `<md5>/` 布局不变。
- **3 处硬编码 `C:/Users/asus/...`** → `$RS_TEST_TIF` + 仓库相对路径。
