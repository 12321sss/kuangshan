### 关键技术决策
1. **坐标系不走 pyproj**：requirements 明确禁止（3.13 Windows 无轮子），统一用 rasterio 的 `CRS.from_wkt` + `warp.transform_geom`
2. **SHP 解析用 pyshp**（纯 Python，无 GDAL 绑定），不引 fiona/geopandas
3. **监督分类首选随机森林**（sklearn），备选 numpy 自研最大似然
4. **AOI 统一结构**含 `boundaryType`：PERMIT/DISTURBANCE/ECO —— 方案红线要求矿权与扰动边界分开
5. **导入边界即越界基准**：B5 越界检测改为优先取 `aoi_boundary` 的 PERMIT 记录
6. **三张新表**：aoi_boundary / training_sample / classify_run；extractions 不改结构

### 识别出的核心坑（写进文档了）
1. **10m/20m 波段分辨率必须对齐**：B02-B04-B08 是 10m、B11-B12 是 20m，
   直接拼特征矩阵是光谱错位；要统一重采样到 10m 网格（确认 clip_aoi 是"索引 resize"还是"地理重采样"）

3. 地形阴影会被误分为水体/采坑，需坡度坡向掩膜
4. NDVI/NDWI 修正必须"限制性条件"，否则精度不升反降
5. 10m 分辨率测不出坑内台阶，须提前说明
