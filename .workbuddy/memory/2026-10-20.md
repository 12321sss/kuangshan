## 第五轮：重构面积统计口径（用户指出的设计硬伤）

### 用户指出的问题（完全正确）
"地物面积累计不合理——我可以多次提取，数据不就乱了吗？应该按年份月份查看；对比也只能分别对比"

### 根因
地物面积是**存量指标**（某时某刻这块地有多少建筑），原实现按 date 分组用 merge(sum) 把同区域多次提取相加 → 提取两次面积翻倍。属于设计错误，不是 bug。

### 修复（后端）
1. `area-timeseries`：改为 (期|类型|AOI) 三重去重，同期同区域只取最新一条；支持 `granularity=month|year`；返回 `{granularity, rows, note}`；rows 加 recordCount
2. `change-summary`：改为按 (类型|AOI) 去重取**拍摄日期最新**（不是 id 最新！）
   - 关键坑：用户可能先提 2024 再补录 2022，按 id 取会丢掉真正的最近观测。写 `newerObservation()` 日期优先
3. `pit-forecast`：同 AOI 同月重复提取不再被当成"两期"，避免外推斜率失真
4. `check-trends`：先去重再分组算环比
5. `ShareController.view`：同样改为按日期最新去重

### 修复（前端）
- AnalysisView：加"按月/按年"切换；饼图改为**期次下拉选择**（选某年月看该期构成），彻底去掉"历史累计"；明细表加"记录数"列 + 口径说明
- RemoteExtractView：播放动画自动排除非同一 AOI 的记录；"对比差异"加同 AOI 校验；**新增"复用上次 AOI"按钮**（手圈两次点位有偏差会导致区域指纹不同，进而时序匹配失败/面积重复统计）
- CompareView：加同 AOI 校验
- ReportView：适配 areaTimeseries 新返回结构

### AOI 指纹说明（已确认合理）
ExtractionService.aoiSignature = 四舍五入5位 → Set去重 → TreeSet排序 → hashCode，对顶点顺序/起点不敏感。但要求顶点集合完全一致，故加"复用上次 AOI"按钮规避手圈偏差。

### 验证
原始记录：id6(2022-10,21.08ha,签名19618364) / id5(2023-10,23.65ha,同签名) / id4(2024-12,62.17ha,签名60243738)
构成合计 85.82ha = 23.65(同AOI取较新) + 62.17 ✓ 正确（旧逻辑会得 83.25 取错）

## 第八轮：平台重新定位为"矿山安全评估"方向（用户提出）

用户决定：物联网先放一放，主线收窄为**矿山地表变化 + 开采安全风险筛查**，要求评估"用遥感提取的矿坑坡度变化做安全性评估"，并把植被/水体覆盖融合判断安全开采。

产出 **docs/08-矿山安全评估方向-功能评估表.md**。

### 核心专业思路（四层多因子风险模型）
- A 形态因子：边坡角/坡高/台阶坡面角/坡度变化率/采坑体积（需 DSM）
- B 覆盖因子：FVC植被覆盖度/裸地占比/坑内积水/尾矿库水位/复绿速率（Sentinel-2 即可）
- C 空间关系：越界开采/距生态红线/排土场汇流路径/道路切坡
- D 变化速率：采坑扩张速率(ha/年、m/年)/堆高速度/扰动新增速率
- 输出：5 级风险栅格图 + 热点清单（位置+因子实测值+证据+建议核查方式），不是给一个总分

### 关键技术判断（避免过度承诺）
- **30m 公开 DEM 算不出矿坑边坡角/台阶坡面角/坑深/体积**（矿坑直径 500-1500m、深 100-300m，30m 像元把边坡细节抹平）
- 30m DEM 只能做：区域坡度、汇流累积（排土场选址风险）、地形背景
- 精细边坡指标必须亚米级 DSM（无人机航测 1-5cm 或 GF-7/Pléiades 立体像对）
- **二维替代方案**（无需 DSM）：采坑面积/周长/形状指数/边界推进速度(m/年)/凸出度 —— 专业且客户看得懂

### E1 在线提取开放七类（完成）

- 七类判别逻辑（对齐方案表 6）：
  - VEGETATION: NDVI > 0.25
  - WATER: MNDWI > 0
  - BARE: 低植被+非水+SWIR 信号

### A1 DEM 接入（完成）
- **放弃 Copernicus GLO-30**：其 COG 用 predictor=3（浮点预测器），需按行做字节平面还原+uint32累加+大端组装，实测反复得到 ±3.4e38 垃圾值（踩坑：① reshape 要 (h,4,w) 不是 (4,h,w)；② cumsum 必须 uint32，uint16 会溢出）

- dem.py：read_dem_window（Web Mercator 瓦片拼接+裁剪）、slope_aspect（Horn 三阶差分）、flow_proxy（3x3 邻域低洼度×坡度反权）、terrain_summary（5 级坡度分布）
