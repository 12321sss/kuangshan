### 网络踩坑
GitHub git clone 直连被代理 502，ghproxy 镜像 SSL 失败，gh-proxy index-pack 失败。
**最终用 curl 下载仓库 zip**（`https://github.com/12321sss/kuangshan/archive/refs/heads/main.zip`）成功。
系统代理 http://127.0.0.1:50838 可直连 GitHub（curl 200）。

### 合并方式（本地非 git，采用文件同步）
1. 备份本地源码到 /tmp/backup_local_src
2. 用远程覆盖本地 frontend/src、backend-java/src、inference/*.py、docs、根目录配置
3. 保留本地运行时环境（node_modules/.venv/target）和 .workbuddy 记忆
4. 远程 requirements.txt 与本地一致，无新增依赖
