## 第二十七轮：RSEI 生态指数 + 矿山安全指数 + 批量时段提取 + DEM 修复

用户四个需求：①批量要支持「多类型×多年份」②加 RSEI 生态指数（分析+报告）③DEM 地形分析点了没内容 ④设计矿山安全指数（可参考论文）。后续追加：⑤批量要支持「时间段+时间间隔」。

### ③ DEM 地形分析 bug（先修）
**根因两个**：
1. `dem.py` 硬限制 AOI 超 16 张瓦片直接 `raise ValueError("AOI 过大")`
2. 前端只弹一闪而过的 toast，用户以为点了没反应
**修法**：AOI 超限时**自动逐级降 zoom**（z14→z13→z12→z11→z10）而非拒绝。
实测 12km AOI → z13、35.7m/px、12 瓦片；4km → z14、8.9m/px、6 瓦片。
工具栏 `.map-toolbar` 加 `flex-wrap: wrap` + `right: 190px`（之前按钮被挤出视野）。

### ② RSEI 生态指数（inference/ecology.py 新建）
方法：徐涵秋 2013 RSEI，PCA 第一主成分。
**关键限制**：Sentinel-2 无热红外波段（B10 是卷云检测），**无法算 LST**，故实现为
**三因子 RSEI-3（绿度NDVI + 湿度WET + 干度NDBSI）**，必须在界面/报告标注非完整版。
- WET 用 S2 缨帽变换系数（Baig 2014）；NDBSI=(SI+IBI)/2
- sentinel.py BAND_KEYS 补 B12=swir22（RSEI 需要）
- 接口 `/api/v1/ecology/rsei`，支持 compare_start/compare_end 两期对比
- **实测验证**：均值 0.5883，PC1 载荷 [绿度+0.472, 湿度+0.599, 干度−0.647]，
  符号完全符合物理意义（干度为负是关键正确性标志），解释率 80.9%

### ④ 矿山安全指数（并入 risk.py，未另建文件）
发现远程 risk.py 已有五维风险（形态/扩张/越界/覆盖/水文），本机在此基础上：
- **新增第六维「生态风险」**（输入 RSEI，`_ecology_risk()`）

- 结果新增 `safetyIndex = 100 − 风险分` + `safetyLevel`（客户习惯「分越高越安全」）
- Java SafetyController 自动调 ecology 接口拿 RSEI 再传给 risk.evaluate
- 早期写的 safety.py 已删除（功能并入 risk.py，避免重复实现混淆）

## 第二十八轮：修 label for 警告 + 成功推送 GitHub

### label for 警告根因
浏览器报 `Incorrect use of <label for=FORM_ELEMENT>`（for 指向不存在的元素 id）。

查 Element Plus 源码（form-item.vue_...lang.mjs）：
```js
const labelFor = computed(() => props.for ?? (inputIds.value.length === 1 ? inputIds.value[0] : void 0));
resolveDynamicComponent(labelFor.value ? "label" : "div"), for: labelFor.value
```
逻辑是：**内部恰好注册 1 个控件 id 时才渲染 `<label for>`**，0 个或多个渲染 `<div>`。
问题在于 el-checkbox 在 form-item 上下文里（isLabeledByFormItem=true）**不落地自己的 input id**，
于是 form-item 渲染了 label for=某个不存在/未渲染的 id → 浏览器告警。

最典型触发：**form-item 内只有单个 el-checkbox**（ReportView「安全评估」）。

### 修法
对「内部不是单一可关联输入」的表单项，弃用 el-form-item 的 label 机制，改自定义行布局：
```html
<div class="fi-row"><div class="fi-lbl">标题</div><div class="fi-ctl">控件</div></div>
```
`.fi-lbl` 定宽右对齐模拟 label-width，无 for 属性 → 规范合规。

改动位置：
- ReportView.vue「安全评估」（单 checkbox）
- RemoteExtractView.vue 批量面板「地物类型」（checkbox-group）、「自动入库」（switch+文本）

未改的 6 处（经源码逻辑分析不会报）：el-slider(有 show-input,1个真实 input)、
el-radio-group(多个 id→div)、perm-box(多个 id→div)。若用户仍看到警告再处理。

### GitHub 推送成功（关键经验）
**代理是罪魁祸首**：git config 里设了 http.proxy=127.0.0.1:50838 → `CONNECT tunnel failed 502`。
**禁用代理直连可以成功**：`git -c http.proxy= -c https.proxy= push`。已从本地 git config 清除代理。
- 本地分支原为 master，远程是 main → `git branch -M main`
- 本地历史与远程**无共同祖先**（本地是独立 init 的）→
  用 `git merge origin/main --allow-unrelated-histories -X ours`（保留远程历史节点，冲突以本地为准）
- 推送结果：`236208b..037dfd7 main -> main`，远程与本地 HEAD 一致

### 经验
遇到 git 连 GitHub 失败，**先试 `-c http.proxy=` 禁用代理**，再考虑镜像。
